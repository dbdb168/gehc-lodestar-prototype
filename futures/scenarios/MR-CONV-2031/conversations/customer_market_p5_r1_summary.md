# Customer and market, phase 5, round 1, summary

## Key points

The Federal Register API returns no Section 232 proclamation on medical devices as of 11 October 2026, so the buyer-side reading of U1 leans toward trade staying a cost (N08, N10, N18, N36; source: Federal Register API, 11 Oct 2026).

The European origin rule for medical tenders above 5 million euros stays in force with no expiry, which keeps the China plant regional but stops nothing (N17, N28, N36; source: EUR-Lex 2025/1197, carried from phase 2).

The ten most recent clearances in product code LNH are low-field, portable or software, and none is a sealed 3 tesla magnet, so U2 leans toward helium still deciding (N05, N19, N34; source: openFDA 510(k), 11 Oct 2026).

The FDA shortages list carries no imaging code as of 16 June 2026, which is consistent with both ends of U2 while helium is allocated rather than absent (N01, N34, N36; source: FDA shortages list).

Low-field clearances are the main false signal on U2: they use little helium but do not replace the fleet tenders buy (N36; Panel judgement).

## In one hundred words

Four buyer-side indicators cover the axes. Two are live feeds today: the Federal Register search for a Section 232 medical proclamation (U1) and the openFDA 510(k) list for product code LNH read for sealed designs (U2). Two need a person each quarter: the EUR-Lex origin rule for medical tenders (U1) and the FDA device shortages list (U2). On 11 October 2026 both axes lean toward end A: no medical proclamation exists, the European rule stands unchanged, no sealed 3 tesla clearance has appeared, and no imaging code is in shortage. The reading that would move tender pull fastest is a 3 tesla sealed clearance.
