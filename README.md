# Lodestar Command Center

A live supply-chain command centre for a medical imaging OEM. It combines real-time public signals with a synthetic OEM network.

- `CLAUDE.md`: operating rules for Claude Code
- `docs/BUILD_BRIEF.md`: the plan
- `docs/ENVIRONMENT.md`: credentials, network access and deployment
- `docs/MODEL_COSTS.md`: model cost comparison
- `data/network.json`: synthetic OEM network, with a provenance tag on every value
- `prototype/`: the earlier static prototype (UX reference)

The map app (`app/`, added on day 1) is based on [World Monitor](https://github.com/koala73/worldmonitor) and licensed AGPL-3.0.
